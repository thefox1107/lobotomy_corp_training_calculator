# LobotomyCorpCal C++ 桌面版

双击 `LobotomyCorpCal.exe` 即可在 Windows 本地运行。程序为独立 C++ Win32 可执行文件，运行时不需要 Node.js、Java、Python 或浏览器。编辑后会自动重新计算，并把员工属性、目标、工作对象、偏好补录及已完成次数保存在程序旁边的 `LobotomyCorpCal.ini`。

## 使用

1. 输入员工姓名与勇气、谨慎、自律、正义的当前具体数值和目标数值。
2. 从下拉列表选择异想体。危险等级会自动绑定，不可手动更改。
3. 按实际情况选择属性上限，并填写普及培训手册、培训部加成、预计 PE-BOX、工作结束时生命和精神比例。
4. 查看四种工作的预计增益与计划次数。随时修改“已完成”次数，剩余次数和下一项推荐立即更新。

危险等级目录包含 84 个条目，内置已核对的 5 个对象的五级工作偏好。其他对象可在右侧按 Wiki 的 I–V 级数值补录四种工作偏好；缺少偏好时，程序会明确提示，不会编造推荐。

## 编译

已附带编译完成的 `.exe`。若需要重编译，在已安装 MinGW-w64 并可使用 `g++` 的 Windows 电脑上运行 `build.cmd`。编译脚本会同时运行计算核心测试。`catalog.hpp` 已包含完整的等级目录，编译不依赖其他文件夹。`generate_catalog.mjs` 仅用于以后从网页版本的数据重新生成目录。

计算公式、参考来源和估算限制见网页版本的 [说明](../LobotomyCorpCal/README.md)。桌面版与网页版本共用相同的品质门槛、工作系数和培训部系数。已完成次数是计划进度；如果游戏中的实际属性已变化，请同步更新“当前”值。
