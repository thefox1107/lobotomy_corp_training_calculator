# 脑叶公司员工训练计算器

用于估算员工进行异想体工作时的属性增益，以及达到训练目标所需的次数。程序为 Windows C++ 桌面应用，下载 `.exe` 后可以离线运行。

> 玩家制作的非官方辅助工具。显示的次数是规划估算值，请以游戏内实际结果为准。

## 下载与启动

1. 从 [GitHub Releases](https://github.com/thefox1107/lobotomy_corp_training_calculator/releases) 下载 `LobotomyCorpCal.exe`。如果暂时没有发布附件，可按下方说明从源码构建。
2. 将 `.exe` 放入可写入的普通文件夹，双击运行。程序会在同一目录保存 `LobotomyCorpCal.ini`，无需安装 Node.js、Java 或 Python。

当前程序版本为 v0.3.4。启动时会在后台检查本仓库的最新正式版 Release；离线时仍可照常使用。发现更新后，程序会询问是否下载。下载先尝试 GitHub，失败时尝试 [GH-Proxy 镜像](https://gh-proxy.com/docs/github-accelerator)，并按 Release 提供的 SHA-256 摘要校验文件；缺少摘要的附件不会自动安装。下载成功后关闭程序，再次启动旧版 exe 即会自动替换并打开新版。更新文件暂存在 exe 所在目录，因此该目录需要可写；如有其他程序实例仍在运行，需先全部关闭。每次发布新版时，需同步修改 `native/updater.hpp` 中的 `APP_VERSION`，并上传名为 `LobotomyCorpCal.exe` 的 Release 附件。

国内镜像是第三方代理。若 GitHub API 不可用，版本信息与校验摘要也会经由镜像获取。

窗口支持拖动边框调整大小和最大化。拖动边框期间暂缓重绘，松开后更新布局。放大时，详细模式的员工档案与工作偏好会一起伸展；缩小时，列表和卡片会收紧布局，文字与控件保持原大小。详细模式空间不足时可使用水平、垂直滚动条查看完整内容。最小内容区域约为 900 × 500。

## 使用方法

程序启动后默认显示“使用说明”，提供四步入门指引及保存提示。左侧导航分为六页：

1. 简单模式：浏览全部员工的等级、工作对象、推荐工作类型、实际工作类型及其已完成次数。双击“工作对象”或“实际工作类型”单元格可用下拉菜单调整；双击其他单元格进入该员工的详细档案，也可在此新增员工。实际工作类型切换后，已完成工作列显示对应类型原有的次数，不累计四种工作。
2. 详细模式：用顶部标签切换员工。填写姓名、当前属性、目标和各工作类型的已完成次数；`−`、`+` 可逐次调整工作次数。选择工作异想体时，只会列出“当前收容”中的对象，危险等级自动绑定并用对应颜色显示，切换对象保留各工作类型的已完成次数。选择培训条件后，右侧显示偏好与训练结果，并按每种工作列出已完成次数；全部训练完成时推荐卡变绿。下方列有员工品质与属性范围判定表和使用提示。
3. 当前收容：从下拉框选择异想体并点击“添加收容”；列表以对应危险等级的浅色圆角行显示，选中对象后可移除。已被员工选作工作对象的异想体，需要先给相关员工换对象才能移除。首次运行本版时，现有员工使用的对象会自动加入收容列表。
4. 收容推荐：浏览参考工作簿对 84 个异想体的收容、E.G.O 武器、防具和镇压推荐。列表以危险等级对应的浅色圆角行显示，鼠标悬停和选中时会加深底色。点击“编号”“等级”或“收容推荐”表头排序，再次点击可反转方向。编号只比较最后一段数字；等级按 ZAYIN、TETH、HE、WAW、ALEPH 排序；收容推荐升序为特殊说明、论外、高、中、低、极低。选中一行后，下方显示未截断的原表文字；原表空白的镇压栏显示“原表未填写”。
5. E.G.O 库存：仅显示有武器或装备的异想体。在搜索框输入异想体或 E.G.O 名称，可用汉字、完整拼音或拼音首字母查询，也可省略中间的部分字母，例如 `jhsn` 查找“焦化少女”。点击“清除”恢复完整列表。已解锁对象始终排在未解锁对象前；点击“编号”或“危险等级”表头可切换升降序，已解锁对象始终排在未解锁对象前。列表按危险等级显示浅色行，并列出统一的 E.G.O 名称、武器与装备的“已有 / 基础上限”以及两项推荐度。一般推荐度只显示原表的优良差评级与攻击距离，不显示评级后括号中的危险等级字母；有条件的评级会保留条件标签。白夜使用原表中的武器和装备说明，悬停可查看完整文字。选中异想体后，用对应的 `−`、`+` 记录已解锁数量，列表会随状态变化重新排序。只有武器或只有装备的对象，缺少的一类显示 `—`。库存与当前是否收容分开保存。

### 次数说明

每一行对应一种工作及其训练的属性。单次增益按当前属性等级计算一次，计划次数为“目标与当前属性的差值 ÷ 单次增益”向上取整，跨过品质门槛后不改变本次计划的系数；剩余次数为计划次数减去已完成次数，最低为 0。填写“已完成”只更新进度，不会自动改动当前属性。推荐仅从仍需训练且基础工作成功率不低于 60% 的工作中选择；低于 60% 的工作仍显示估算结果，但不会被推荐。

### 保存与迁移

程序自动将员工、收容列表和 E.G.O 库存保存在 exe 同目录的 `LobotomyCorpCal.ini`。将 exe 和 ini 一起备份或复制，即可保留输入与进度。旧版单员工计划会自动载入为第一个员工。

## 数据与估算范围

程序收录 84 个对象，其中 65 个具有常规四类工作的五级偏好数据；19 个工具类或无法收容的对象会显示“没有常规工作”，不参与训练推荐。名称与危险等级按本地参考工作簿核对；收容与装备推荐来自下文注明的参考工作簿；E.G.O 数量上限参考 [Wiki 装备表](https://lobotomycorp.fandom.com/wiki/Equipment) 的基础持有上限，不包含 Gebura 研究增加的数量。武器与防具名称参考 Wiki 的 [E.G.O 武器](https://lobotomycorp.fandom.com/zh/wiki/E.G.O_%E6%AD%A6%E5%99%A8) 和 [E.G.O 护甲](https://lobotomycorp.fandom.com/zh/wiki/E.G.O_%E6%8A%A4%E7%94%B2) 速查表。属性计算参考 [脑叶公司 Wiki 的职员页面](https://lobotomycorp.fandom.com/zh/wiki/%E8%81%8C%E5%91%98)，偏好参考 [异想体页面](https://lobotomycorp.fandom.com/zh/wiki/%E5%BC%82%E6%83%B3%E4%BD%93)。

程序按当前属性品质等级取一次工作系数，并在整段计划中保持不变；健康输出系数沿用原有设定：预计满生命与满精神时，本能、洞察、沟通为 0.4，压迫为 0.5。预计 PE-BOX 按对象危险等级固定为 ZAYIN 7、TETH 8、HE 12、WAW 16、ALEPH 23。程序不模拟实际工作所得 PE-BOX、品质提升后的系数变化、工作中断、受到伤害的过程、异想体特殊能力、饰品或 WAW 连续工作过载。

## 从源码构建

在 Windows 上安装 MinGW-w64 `g++` 和 `windres`，然后在仓库根目录运行 `build.cmd`。生成的程序位于 `dist/LobotomyCorpCal.exe`；脚本会同时运行 C++ 计算测试。编译好的程序运行时不需要 Node.js。

异想体数据源位于 `data/`，`native/catalog.hpp` 由 `node tools/generate_catalog.mjs` 生成。拼音索引已包含在源码中；更新异想体或武器名称后，可运行 `npm install`、`npm run generate:pinyin`，再重新生成目录。程序图标在 `native/app.ico`；需要重新生成时运行 `node tools/generate_icon.mjs`。仅维护这些生成资源时需要 Node.js；数据校验可运行 `node --test tests/catalog.test.mjs`。
